# Fluorescence section

A synthetic three-channel section with 1,800 cells over it. Nothing here is real tissue —
it is generated by [`scripts/prepare_demo_checkpoints.py`](https://github.com/CirroBio/spatial-data-studio/blob/main/scripts/prepare_demo_checkpoints.py),
so the demo needs no downloads and can be rebuilt whenever the checkpoint format moves.

## Things to try

- **Colour by category.** The cells carry a `cell_type` column with four values. The
  legend doubles as a filter — click a category to isolate it and dim the rest.
- **Colour by a gene.** Each cell type has its own block of enriched marker genes
  (`TUM*`, `STR*`, `IMM*`, `VES*`), so picking one lights up a single cluster.
- **Work the channels.** The image has three channels (DAPI, CD3, PanCK). Toggle them
  individually and drag their contrast limits; the change is per channel.
- **Open the Embeddings view.** The same four groups separate in a 2-D embedding, and
  the colouring follows whatever you picked on the spatial canvas.

## How it was made

The dataset is built as an ordinary `SpatialData` object — one `Image2DModel` element
and one table — written to a `.zarr` store, then opened through the app's own session
machinery so it picks up the default displays, and saved with
`persistence.store.save_spatialdata`. That is the same path
[the offline CLI](/DEVELOPMENT#run-offline-headless-cli--nextflow) takes, which is why
the result is a checkpoint the viewer can open with no server behind it.
